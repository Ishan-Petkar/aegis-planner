# Changelog

## 1.0.0

First public release.

- Planning engine: world graph with dynamic road status, A* routing, CSP team assignment (AC-3 and backtracking), transparent risk scorer, verification engine and a repair loop.
- Three planners for comparison: Baseline Planner, AEGIS + Solvers, Full AEGIS.
- Six Pune scenarios with scripted mid-run events, and a scenario builder for custom maps.
- Web app: Overview, Mission Control, Scenario Builder, Experiments and Method pages, responsive down to phone width.
- Ablation experiment runner producing the results tables and charts.
- Google Colab notebook with the full model code and plots.
- One-command launchers for macOS, Linux and Windows.
